# Web SIM Kesiswaan

React + Vite untuk Admin, Kesiswaan, dan Kepala Sekolah. Dari folder ini jalankan `npm ci`, salin `.env.example` ke `.env` bila belum ada, lalu `npm run dev`.

API default: http://localhost:3000/api/v1. Jalankan backend terlebih dahulu. Gunakan `npm run lint` dan `npm run build` sebelum pull request. Profil demo hanya berada di memori. Lihat [panduan tim](../docs/development/README.md).
